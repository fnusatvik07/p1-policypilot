WI-040 — Branch-submitted claim handoff

Type: Work Instruction
System(s): ClaimTrack, CardView, Corvane Card Services portal
Owner: Darnell Price, Manager, Operations Training
Effective date: 2017-04-01
Status at issue: Active
Version: 1

Purpose

Use this work instruction when a branch submits a consumer dispute or claim and the branch needs Claims Intake to assume ownership in ClaimTrack. This page covers the handoff steps only; case classification, coverage, and investigation routing are addressed in the related procedure set.

Before you start

Before you start - Confirm the branch has completed the customer-facing intake in TellerOne and attached the branch narrative and any source documents. - Have the customer’s full name, account number, last four digits of the card number, branch number, and date received available. - Use CardView to confirm the card status and the last posted transaction date before creating or updating the case. - If the claim involves a network chargeback or merchant reversal already visible in Corvane, note the reference number before handoff. - If the branch submission is incomplete, return it to the branch for correction rather than opening a duplicate record in ClaimTrack.

Procedure

  1. Open ClaimTrack.
    Sign in using your standard network credentials and select Claims Intake Queue from the left navigation pane.

  2. Search for the branch submission.
    In the search bar, enter the customer last name and account number, then click Search. If no result appears, search by card last four and branch number.

  3. Review the incoming record.
    Open the claim and verify:

  4. branch location and received date
  5. claim type selected by the branch
  6. customer contact details

  7. attached notes, letters, and supporting images

  8. Check CardView before accepting the handoff.
    In a second window, open CardView and review the card profile:

  9. card status
  10. account standing
  11. transaction history around the disputed date

  12. whether the card is linked to the correct deposit account

  13. Check Corvane for processor activity when applicable.
    If the claim is a debit, credit, or prepaid card item that may have merchant or network activity, open the Corvane Card Services portal and look up the card account. Save any visible reference numbers or dispute notes to the ClaimTrack record.

  14. Validate the submission against the branch narrative.
    Compare the branch statement with the account and processor views. If the submission appears to describe the wrong transaction type, do not reclassify the claim here. Route the case to the Claims Intake supervisor queue for correction.

  15. Assign the case to Claims Intake.
    In ClaimTrack, click Assign To and select Claims Intake - Branch Handoff. Add a concise internal note that includes:

  16. branch name
  17. date received
  18. CardView review complete
  19. Corvane review complete, if applicable

  20. any missing documentation

  21. Attach branch materials.
    Click Attachments and upload the branch form, narrative, and any scanned support received from the branch. Confirm the file names are readable and complete.

  22. Update the case status.
    Select Handoff Complete from the status menu. Enter the disposition comment, then click Save.

  23. Send the acknowledgment to the branch.
    Use the standard branch reply template in ClaimTrack to confirm that Claims Intake has received the submission. Include the ClaimTrack case number and any additional documentation needs.

  24. Close your work item.
    Return to the queue dashboard and confirm the item no longer appears in Open Branch Submissions.

Tip If the claim is already visible in Corvane with a processor-generated reference, copy that reference into the ClaimTrack notes before saving. This reduces duplicate research later.

Warning Do not create a second ClaimTrack record if the branch submission already exists under a different queue. Use the existing case and update the history instead.

Tip If CardView shows a closed or replaced card, still complete the handoff if the disputed transaction posted to the linked account. Card status alone does not determine whether the branch submission should be accepted.
