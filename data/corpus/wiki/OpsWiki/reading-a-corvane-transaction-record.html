WI-009 — Reading a Corvane transaction record

Type: Work instruction
Version: 2
Effective / issued date: 2023-06-05
Status at issue: Active
Owner: Darnell Price, Manager, Operations Training

Purpose

Use this page to read a Corvane transaction record when reviewing a debit, credit, or prepaid card dispute. Corvane is the third-party processor used for card transaction and chargeback activity. This instruction explains where to find the record, how to match it to the claim, and which fields are typically relied on during investigation work.

This version reflects ClaimTrack 2.0 and the current CPS-SOP numbering. For dispute handling steps, use this page together with:

  • CPS-SOP-203 — Claim Classification and Coverage
  • CPS-SOP-204 — Debit Card Point-of-Sale Disputes
  • CPS-SOP-209 — Credit Card Billing Error Disputes
  • CPS-SOP-217 — Chargeback Filing and Recovery
  • CPS-SOP-234 — Coordination with Corvane Card Services

[!NOTE] Before you start

Confirm the claim number in ClaimTrack and the last four digits of the card number before opening Corvane. If the claim is a duplicate, a repeat claim, or tied to a merchant credit, review the applicable procedure first so you are reading the correct transaction record.

You will need access to:

  • ClaimTrack 2.0
  • CardView
  • Corvane Card Services portal

Use only the current claim record. Do not rely on screenshots or notes copied into shared files when a live system record is available.

Procedure

  1. Open the claim in ClaimTrack 2.0.
  2. Sign in to ClaimTrack and open the claim from the work queue or search results.
  3. Search by claim number, card number, or customer name.
  4. Verify the dispute type, transaction date, and deadline clock displayed on the case banner.

  5. If the deadline clock is paused, extended, or otherwise flagged, note the status before moving on.

  6. Review the card details in CardView.

  7. From the ClaimTrack claim, select the linked card/account record or open CardView separately.
  8. Confirm the product type: debit, credit, or prepaid.
  9. Verify the masked card number, account status, and cardholder name.

  10. Check whether the card was reissued, closed, or replaced before the disputed date.

  11. Open the Corvane portal.

  12. Launch the Corvane Card Services portal in your browser.
  13. Sign in using your network credentials.

  14. Select the transaction search or account activity function.

  15. Search for the transaction.

  16. Enter the masked card number, transaction date, or amount as available.
  17. If the claim references a merchant name, use the merchant search field.
  18. Run the search and open the matching transaction record.

  19. If multiple results appear, compare the card suffix, date, and amount before opening a record.

  20. Read the transaction header.
    Confirm the following first:

  21. Transaction date and time
  22. Posting date, if shown
  23. Amount
  24. Merchant name and merchant location
  25. Card type and account identifier

  26. Authorization response, if present

  27. Review authorization and settlement details.

  28. Check whether the item was approved, declined, reversed, or adjusted.
  29. Compare the authorization amount to the settled amount.
  30. Look for partial captures, tips, or split transactions when the amounts differ.

  31. If a merchant credit appears, note the credit date and amount.

  32. Check the transaction status and dispute indicators.

  33. Review any chargeback, retrieval, representment, or reversal indicators shown in Corvane.
  34. Note whether the item has already been worked by Chargeback Recovery.
  35. Confirm whether the transaction is still open, final, or closed.

  36. Capture any reference number shown in the record for comparison to ClaimTrack and CardView.

  37. Document the record in ClaimTrack.

  38. Return to ClaimTrack.
  39. Add case notes that summarize the Corvane record.
  40. Record the fields used to support the next action, such as merchant name, amount, dates, status, and reference number.
  41. Attach or reference any system-generated record permitted by procedure.

[!TIP] When the merchant name in Corvane does not match the customer’s description, compare the transaction date, amount, and location before concluding it is the wrong item. The posted merchant descriptor may differ from the store name the customer uses.

[!WARNING] Do not treat a single authorization screen as the complete transaction history. Some disputes require both authorization and settlement data before the record can be read correctly.

Field guide

Field What it usually shows
Transaction date/time When the transaction was initiated or posted in Corvane
Merchant name The descriptor associated with the transaction
Amount Original, settled, adjusted, or credited value
Status Open, closed, reversed, credited, or disputed
Reference number Identifier used when comparing Corvane, CardView, and ClaimTrack
Network indicator Card network or processing flag tied to the transaction
