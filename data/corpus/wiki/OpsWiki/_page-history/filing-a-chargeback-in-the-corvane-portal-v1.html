WI-017 — Filing a chargeback in the Corvane portal

Type: Work instruction
Status at issue: Active
Effective/issued date: 2017-04-01
Version: 1
Owner: Darnell Price, Manager, Operations Training

Purpose

This page explains how Claims Intake associates file a debit or credit card chargeback in the Corvane portal after a claim has been screened, classified, and routed in ClaimTrack. Use this instruction together with DOP-201, DOP-203, DOP-204, DOP-209, DOP-217, and DOP-234.

Before you start

Before you start - Confirm the claim is already opened in ClaimTrack and the case status allows chargeback filing. - Review CardView for the card number, product type, transaction date, and merchant information. - Confirm the customer’s claim type and reason code match the chargeback reason selected in Corvane. - Have the supporting evidence ready in the case file before submitting the chargeback. - Use the correct customer identifier and case number in all systems to avoid duplicate filings.

Procedure

  1. Open the case in ClaimTrack.
    Search for the claim using the customer name, claim number, or account number. Open the case and confirm the disposition path is chargeback-related.

  2. Verify the card and transaction in CardView.
    From ClaimTrack, launch CardView for the account. Review:

  3. card product
  4. last four digits
  5. transaction date and amount
  6. merchant name and location

  7. any prior provisional credit or merchant credit activity

  8. Confirm the chargeback category.
    In ClaimTrack, check the case classification and supporting notes. If the claim requires a fraud referral or a different dispute path, stop and route the case under the applicable DOP instruction before filing in Corvane.

  9. Open Corvane Card Services.
    From the approved operations desktop, sign in to the Corvane portal. Use the card servicing menu to locate the appropriate customer account.

  10. Search for the account in Corvane.
    Enter the primary account number or customer-linked card number. Confirm that the account returned in Corvane matches the account in ClaimTrack and CardView.

  11. Select the chargeback workflow.
    In Corvane, choose Disputes or Chargeback Filing from the account menu. Select the transaction identified in CardView.

  12. Enter the case details.
    Complete the required fields using the information already validated in ClaimTrack:

  13. reason code
  14. transaction date
  15. amount
  16. merchant
  17. claim number
  18. narrative summary

  19. evidence reference, if applicable

  20. Attach or reference supporting documents.
    If the Corvane workflow permits attachments, upload only the documents approved for the case. If the workflow uses references instead, enter the document control note from the case record. Do not add materials that are not part of the claim file.

  21. Review for accuracy.
    Before submitting, compare Corvane against ClaimTrack and CardView one final time. Confirm spelling, dates, amount, and reason code. Correct any mismatch before filing.

  22. Submit the chargeback.
    Submit the filing in Corvane and record the confirmation number in ClaimTrack case notes. If Corvane returns an error, do not resubmit until the error is understood and resolved.

  23. Update the case record.
    In ClaimTrack, note the filing date, Corvane confirmation number, and any next action required. Move the case to the appropriate pending queue, if applicable, using the standard work queue process.

Tip Keep ClaimTrack, CardView, and Corvane open together during filing. This reduces field errors and helps ensure the account, transaction, and reason code all align.

Warning Never file a chargeback from Corvane unless the underlying claim is already established in ClaimTrack. Filing without a valid case record may create duplicate work and an inaccurate dispute trail.
