Sending the written confirmation request

Created by Darnell Price · Last updated 2017-04-01 · Version 1

WI-006 — Sending the written confirmation request

Type: Work instruction
System(s): ClaimTrack, CardView, Corvane Card Services portal
Owner: Darnell Price, Manager, Operations Training
Status at issue: Active
Effective/issued date: 2017-04-01
Version: 1

Purpose

Use this work instruction when a claim requires a written confirmation request after the oral notice has been completed. This page explains how to prepare the request, confirm the customer’s contact details, and send the request from ClaimTrack while verifying account information in CardView and, when applicable, Corvane Card Services.

This page supports DOP-202 — Oral Notices and Written Confirmation and should be used together with the claim record in ClaimTrack.

Before you start

Confirm the following before sending the request:

  • The claim is already created in ClaimTrack and the oral notice has been documented.
  • You have the correct customer mailing address on file.
  • You have the card product details needed to route the request correctly.
  • If the claim is tied to a card transaction, you have access to CardView; if the transaction is processed through Corvane, you have access to the Corvane Card Services portal.
  • You are working from the active claim record and not a duplicate or closed case.

Procedure

  1. Open the claim in ClaimTrack.
  2. Sign in to ClaimTrack.
  3. Search for the claim by case number, customer name, or account number.

  4. Open the claim and review the case summary to confirm the reason for the written confirmation request.

  5. Verify the customer and account details in CardView.

  6. Open CardView in a separate browser window.
  7. Search by masked card number or deposit account number.
  8. Confirm the customer name, mailing address, and card product on the servicing screen.

  9. If the address differs from ClaimTrack, use the address shown on the servicing record and notify your lead if the record appears incomplete.

  10. Check the transaction source in Corvane, if applicable.

  11. Open the Corvane Card Services portal.
  12. Locate the transaction or claim reference using the card number and transaction date.
  13. Confirm whether the item was processed as debit, credit, or prepaid.

  14. Review the transaction status to ensure the request is being sent for the correct card channel.

  15. Navigate to the written confirmation task in ClaimTrack.

  16. Return to the claim record in ClaimTrack.
  17. Select the Actions menu.
  18. Choose Send Written Confirmation Request.

  19. Complete the prompt to open the confirmation form.

  20. Complete the request details.

  21. Select the claim type from the available list.
  22. Enter the date the oral notice was completed.
  23. Verify the mailing address field populated from the customer record.

  24. Add a short note if the request requires special handling, such as a corrected address or pending system verification.

  25. Review the preview before sending.

  26. Select Preview to review the request text.
  27. Confirm the customer name, account reference, and mailing address.

  28. Check for obvious formatting errors, missing fields, or mismatched product information.

  29. Send the request.

  30. Select Send in ClaimTrack.
  31. Wait for the system confirmation message.
  32. Confirm the request status changes to Sent.

  33. Record the send timestamp in the claim activity log if it does not auto-populate.

  34. Close out the review.

  35. Add a case note summarizing what was verified in ClaimTrack, CardView, and Corvane.
  36. Save and exit the claim.
  37. If any system returned an error or the customer record could not be verified, escalate the case to your supervisor before proceeding.

Tip

If the customer has multiple cards or multiple active accounts, verify the exact account in CardView before sending the request. A valid claim on the wrong account creates avoidable rework.

Warning

Do not send the written confirmation request from a draft or test claim. Always confirm the case status in ClaimTrack before using the send function.

Tip

Keep your notes factual and brief. Use the claim record to capture only what was verified and what was sent.
