WI-004 — Attaching evidence to a claim

Type: Work instruction
Status at issue: Active
Version: 1
Effective/Issued: 2017-04-01
Owner: Darnell Price, Manager, Operations Training

This page explains how Claims Intake associates attach customer-provided and third-party evidence to an open claim record. Evidence must be added to the claim file promptly so the investigator can review all available documentation in one place. Use ClaimTrack for the claim record, CardView for account verification, and Corvane Card Services for processor-side support items when applicable.

Before you start

Confirm that you have: - The correct ClaimTrack case number - The customer’s claim type and disputed transaction date - The evidence file in an approved format - Access to ClaimTrack, CardView, and the Corvane portal

Do not attach evidence to the wrong claim or to a closed case. If you discover a mismatch after upload, stop and notify your lead before making further changes.

Procedure

  1. Open the claim in ClaimTrack.
    Sign in to ClaimTrack and search for the claim using the case number, customer name, or transaction reference. Open the claim from the results list and confirm the status is still open.

  2. Verify the account and transaction details in CardView.
    Launch CardView and confirm the masked account number, product type, and disputed transaction details match the claim record. Use this step to make sure the evidence you are about to attach belongs to the correct card or deposit account.

  3. Review the evidence file before uploading.
    Check that the file is legible, complete, and relevant to the claim. Typical evidence includes customer correspondence, receipts, merchant statements, screenshots, or processor reports. If the file is password-protected or unreadable, return it to the source for correction before proceeding.

  4. Return to ClaimTrack and open the Evidence panel.
    In the claim record, select Evidence from the left-hand menu. If the evidence section is collapsed, expand it to view existing attachments and upload controls.

  5. Select Add Attachment.
    Click Add Attachment. The upload window opens. Enter the evidence description in the notes field using plain language, such as:

  6. Customer receipt dated 03/18/2017
  7. Merchant email confirming refund status

  8. Cardholder affidavit and supporting screenshots

  9. Choose the file and upload.
    Click Browse or Choose File, select the evidence file from your approved location, and click Upload. Wait for ClaimTrack to display the attachment in the claim file before continuing.

  10. Confirm the attachment saved correctly.
    Review the document name, upload date, and notes. Open the file from ClaimTrack to confirm it displays correctly and is attached to the intended case.

  11. Attach Corvane evidence when the item came from processor research.
    If the supporting material was obtained from Corvane Card Services, sign in to the Corvane portal and locate the relevant processor record. Download the report or image package, then return to ClaimTrack and attach the file using the same upload process above. Do not store Corvane files outside the claim record once the attachment is complete.

  12. Update the claim notes.
    Add a brief note in ClaimTrack stating what was attached and where it came from. Keep the note factual and concise. Example: “Attached merchant correspondence received 04/01/2017 and Corvane dispute image package.”

  13. Close the screen without changing claim disposition.
    Save your work and leave the claim in its current status. Evidence attachment does not by itself approve, deny, or close a claim.

Tip

Use descriptive file names when the source system allows it. Clear names make later review faster, especially when multiple documents are attached to the same case.

Warning

Never attach evidence from one customer to another customer’s claim, even if the transaction date or merchant name appears similar. If you discover a mismatch, escalate immediately to your supervisor.

Tip

If the file is large, upload it one document at a time rather than combining unrelated materials into a single attachment. This makes retrieval and quality review easier under DOP-227 and DOP-229.
