WI-016 — Requesting merchant information

Type: Work instruction
Version: 1
Effective/Issued date: 2017-04-01
Status at issue: Active
Owner: Darnell Price, Manager, Operations Training

Purpose

Use this procedure when a disputes associate must obtain merchant information to support a debit, credit, or prepaid claim. The request may be needed to confirm merchant contact details, store location, transaction descriptors, or supporting documentation for investigation.

This page supplements the intake and investigation procedures in the DOP series. Follow the applicable dispute type procedure for case handling, then use this work instruction when merchant contact is required.

Before you start

  • Confirm the claim is already opened in ClaimTrack and the transaction is identified.
  • Have the customer’s case number, transaction date, amount, and merchant descriptor available.
  • Use only the merchant request path approved for the claim type.
  • Do not contact the merchant directly unless the case owner or supervisor instructs you to do so through Corvane Card Services.
  • Document all outreach attempts in the case notes before closing the task.

Procedure

  1. Open the claim in ClaimTrack.
    From the ClaimTrack Work Queue, search by case number or customer name. Open the claim record and verify the card type, transaction date, and merchant descriptor.

  2. Review the claim details.
    In the claim header, confirm the dispute reason and the transaction status. If the claim is not assigned to your queue, route it to the appropriate investigation team before proceeding.

  3. Launch CardView.
    Select CardView from the application toolbar. Search for the card account using the masked card number, customer name, or account number.

  4. Confirm merchant-related transaction data.
    In CardView, open the transaction detail screen and review:

  5. merchant name as received from the network,
  6. merchant location information,
  7. terminal or store descriptor,
  8. authorization or posted date.

If the merchant data is incomplete, continue with a Corvane request.

  1. Open the Corvane Card Services portal.
    Select the Corvane link from the approved desktop shortcut. Sign in using your standard operations credentials.

  2. Create a merchant information request.
    In the Corvane portal, choose Chargeback Support > Merchant Inquiry. Enter the ClaimTrack case number in the reference field, then enter the transaction date, amount, and merchant descriptor exactly as shown in CardView.

  3. Select the request type.
    Choose the appropriate request category based on the need:

  4. Merchant contact details
  5. Store/location verification
  6. Transaction support documentation
  7. Descriptor clarification

Use the narrowest request type that addresses the claim.

  1. Add internal notes.
    In the comments box, summarize why merchant information is needed and identify any prior research completed in ClaimTrack and CardView. Keep notes factual and brief.

  2. Submit the request.
    Review the entry for accuracy, then select Submit. Save the Corvane confirmation number in the ClaimTrack notes.

  3. Update ClaimTrack.
    Return to the claim record and add a case note stating:

    • the request was submitted,
    • the Corvane confirmation number,
    • the date and time submitted,
    • any expected follow-up action.

  4. Monitor for response.
    Check the Corvane portal for updates during your normal queue review. When a response is received, attach or summarize the information in ClaimTrack and continue with the applicable dispute procedure.

Tip

If the merchant name in CardView differs from the name on the customer’s receipt, record both versions. Use the name returned by Corvane for merchant outreach and documentation.

Warning

Never overwrite an existing case note when adding merchant request information. Create a new note so the audit trail remains complete.
